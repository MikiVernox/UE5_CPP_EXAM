# UE5_CPP_EXAM
# Project Description

The project is a 3D third-person video game developed in Unreal Engine 5, fully implemented using C++. The game takes inspiration from modern platformers and integrates puzzle-solving mechanics to create a dynamic and engaging experience.

The player controls a character who must overcome various challenges and obstacles within the level. Core features include:

Parkour and movement system: the character can climb and jump across platforms to reach elevated areas.

Environmental puzzles: certain puzzles require moving blocks onto specific zones to activate mechanisms or unlock new paths.

Special power-ups: the player can collect an ability that grants invisibility against laser walls, allowing progression through otherwise blocked sections.

Audio-based puzzle: the player must find special stones that play audio clues in the form of numbers. Once the correct sequence is discovered, it must be entered into a panel to open a locked door.

Checkpoint system: checkpoints are placed throughout the level to ensure progress is saved and the player does not need to restart from the beginning.

The project combines platforming mechanics with logical puzzle-solving, highlighting both C++ gameplay programming and the use of Unreal Engine 5’s systems to deliver a polished prototype.
